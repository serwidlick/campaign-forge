For game masters

Your whole campaign, in a folder you own.

A desktop campaign manager for tabletop game masters. World bible, maps, sessions, timeline and journals, written as plain Markdown on your own disk. No account, no server, works offline. When it is time to play, host a table over your own Wi-Fi.

  • Free and open source
  • Windows, macOS, Linux
  • Plain Markdown files
Download
Finding the latest version…
Windows: run the installer. It installs just for you, no admin rights needed. SmartScreen may say the publisher is unknown because the app is not code-signed. Click More info, then Run anyway.
macOS: Apple Silicon only. Open the disk image and drag Campaign Forge to Applications. If macOS says the app is damaged, open Terminal and run xattr -cr "/Applications/Campaign Forge.app" once, then open it again.
Linux: the AppImage runs on any distribution; mark it executable first. The .deb is for Debian and Ubuntu.

All platforms

    Playing with friends

    Everyone installs the same app. Nothing leaves the room and there are no accounts.

    Share what players may see

    Mark any element as Shared. On maps, choose which pins, routes and territories are visible. Preview the campaign exactly as players will get it.

    Host a table

    Press Host a table and read out the six-digit code. Your laptop serves the table over the local network.

    482 913

    Players join

    On the same Wi-Fi, players pick the table from the welcome screen and type the code. They see the player view live, updating within a second of your edits. No campaign folder needed.

    What is inside

    Everything a campaign needs, linked together by stable IDs.

    World bible

    Characters, factions, creatures, places, items, quests, events and lore. Link anything with @ and see what links back.

    Maps

    Drop in an image, pin places, draw routes and territories, set a scale and measure travel time by foot, horse or wagon. Nest maps inside maps.

    Sessions and arcs

    Plan each session as an ordered list of beats, mark the encounter and the cliffhanger, and group sessions into arcs.

    Timeline and journal

    Define your own calendar, months, weekdays and eras. Dated events, sessions and journal entries line up on one timeline with a today marker.

    Wheel and graph

    An overview wheel puts every element one click away, and a graph view shows how everything connects through links, arcs and pins.

    Assistant, if you want one

    An opt-in chat pane that answers questions by reading your own elements. Uses your own API key, kept in the OS credential manager.

    Just files

    Every element is a Markdown file with a short frontmatter block, inside a folder you choose. Back it up, sync it, read it in any editor. If you stop using Campaign Forge, nothing is locked in.

    Links point at a stable id, never a title, so renaming anything is safe. 

    elements/location/the-rusty-tankard.md
---
id: 7f0c6a2e-…
type: location
name: The Rusty Tankard
tags: [tavern, waterdeep]
shared: true
---
