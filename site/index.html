Campaign Forge

A desktop campaign manager for tabletop game masters. Your world, maps, sessions and journals live as plain files on your own disk. No account, no server. Play at the table over your own Wi-Fi.

Download
Finding the latest version…
Windows: run the installer. It installs just for you, no admin rights needed. Windows SmartScreen may say the publisher is unknown because the app is not code-signed. Click More info, then Run anyway.
macOS: open the disk image and drag Campaign Forge to Applications. The first time, right-click the app and choose Open, because it is not notarised yet.
Linux: the AppImage runs on any distribution; mark it executable first. The .deb is for Debian and Ubuntu.

    Playing with friends

    Game master

    Open your campaign, mark what players may see as Shared, press Host a table and read out the six-digit code.

    Players

    Install the same app, join the same Wi-Fi, pick the table from the list on the welcome screen and type the code. No campaign folder needed.

    What is inside

    World bible

    Characters, factions, places, items, lore. Link anything with @, see what links back.

    Maps

    Drop in an image, pin places, draw routes and territories, set a scale and measure travel time.

    Sessions and arcs

    Plan beats, mark the encounter and the cliffhanger, keep a journal.

    Your files

    Everything is Markdown in a folder you choose. Back it up, sync it, read it in any editor.
