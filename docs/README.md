# Campaign Forge guide

Campaign Forge is a desktop campaign manager for tabletop game masters. Everything you write lives as plain Markdown files in a folder you choose. There is no account and no server, and it works offline. Players on the same Wi-Fi can join your table and see what you share.

This guide covers what the app can do and how to do it. Pages are short and task-shaped; skim the one you need.

## Ideas in one paragraph

A **campaign** is a folder. Inside it, every **element** (a character, a place, a session, a map, a journal entry) is one Markdown file with a few fields at the top. Elements **link** to each other by a stable id, so renaming never breaks anything. **Arcs** group **sessions**, sessions have **beats**, and **journal** entries hang off the campaign, an arc or a session. Mark an element **Shared** and it appears in the **player view**; add a `## Players know` heading to a body and only that section goes out. Press **Host a table** and players on your network join with a six-digit code and watch the shared parts update live.
