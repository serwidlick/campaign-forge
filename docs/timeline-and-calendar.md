# Timeline and calendar

## Your own calendar

Most settings do not run on the Gregorian calendar, so Campaign Forge lets you define one. Open **Timeline** in the sidebar and press the calendar button to edit it:

- **Months**, each with a name and a number of days. Add, remove and reorder them.
- **Weekdays**, any number, and which weekday the first day of year one falls on.
- **Eras**, each with a name, an abbreviation shown after the year, and the year it starts.
- **Today in the world**: the current in-world date. The timeline marks it and says how far away everything else is. Move it forward as the campaign advances.

Every year has the same length. There are no leap years, which keeps date arithmetic exact and matches how most fantasy calendars are written.

The calendar is stored in `campaign.json`, so it travels with the folder.

## In-world dates

Events, sessions and journal entries each have a date picker that uses your months and eras. An event can also have an end date, which the timeline shows as a span.

## The timeline

**Timeline** in the sidebar lists everything with an in-world date, grouped by month, with a marker at today. Click anything to open it. Ctrl+click opens it beside the current element, like everywhere else.

## Events

An **Event** is something that happened or will happen in the world: a battle, a coronation, an eclipse. It has a start date, an optional end date and a body. Share one and players see it with its dates.
